## Teaching the style guide

The coder should not need correcting for the same thing twice. For every correction you
make, report the rule behind it in your report block:

- a rule the guide doesn't have yet: `rule: new | <the rule, stated generally> | <path:line — what you changed>`
- a correction an existing entry already covers: `rule: hit | S12`

Report outcome `learned` if you report any rule lines, `done` if you report none.
