# Declared documents

A declared document is a Markdown file the curator maintains, for example a private note under `notes/`. Its content can be private: a journal message, a report or a command's output names the document, never what it says.

- **Declare** it in `bridge.yaml`: `documents:` maps a name (lower-case letters, digits, hyphens) to `path`, and optionally `rubric` (a `.md` file saying what belongs in it; it outranks proposals) and, for a focal document, `instructions` (a `.md` file that shapes its brag file). `path` ends in `.md` and is under `notes/` or `projects/<project>/documents/`. For a new period, edit `path` or declare another name.
- **Propose** with `ensign document propose <name> "<text>" --evidence "<where it came from>"`. It writes `documents/pending/<name>/<time>-<random>.yaml` and prints only the name. Commit with `ensign journal commit -m "<message that names the document, not its content>"`.
- **Curate** when asked ("curate the documents"): `ensign run --pipeline document-curate`, then dispatch each stage as the run says and run `ensign next` after each. Stages: `curate` (curator) folds proposals into the file and removes them; `brag` (brag-writer) writes `<sheet>.brag.md` beside each declared focal document, from the sheet, its `instructions` file and `notes/focal_style.md`; `feedback` (brag-reviewer) lists brag claims that neither the sheet nor the instructions support. A stage with nothing to do is skipped, so the run needs proposals only when no focal document is declared. A missing instructions or style file is not an error; the run's notes say so. The run fails before any dispatch, naming the document, if the file is hand-written Markdown without its one `starship-document` block, or the rubric is missing; add the block by hand, the curator never overwrites such a file.
- **Feedback** is advisory: if an agent fails to report, the run still succeeds and its notes say the feedback is missing. Relay each feedback agent's findings to the user. They quote the document, so keep them out of commits, journals and summaries. If a feedback agent hangs, `ensign run stop <run>` finishes the run as a success.
- **Never** copy entry, proposal, instructions, style or brag text into a commit message, a run summary or a report. Say "curated <name>: 2 new, 1 dropped".
